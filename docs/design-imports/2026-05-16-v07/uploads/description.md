Roland JUPITER-X este un sintetizator polifonic cu 61 de clape (cu aftertouch), anunțat în septembrie 2019 și disponibil din aprilie 2020. Este flagship-ul liniei ZEN-Core a Roland, alături de JUPITER-Xm (varianta portabilă) și, mai târziu, JUNO-X. Conform paginii oficiale Roland, JUPITER-X folosește motorul digital ZEN-Core cu Analog Behavior Modeling (ABM) pentru a recrea cu fidelitate clasice ca JUPITER-8 (1981), JUNO-106, SH-101 și XV-5080, plus piane RD și un vocoder integrat.

Arhitectura include cinci părți (patru părți play + o parte de ritm), 4000+ tonuri presetate, 256 tonuri user și 90+ kit-uri de tobe. JUPITER-X are I-Arpeggio (algoritmi inteligenți pentru pattern-uri evolutive), efecte ZEN-Core complete (multi-effects, reverb, chorus, delay, EQ master, compresor) și suport pentru Model Expansions descărcabile prin Roland Cloud (JUPITER-8, JD-800, JX-8P, SH-101, Vocal Designer și altele).

Designul reia elementele estetice ale flagship-urilor Roland din anii '80, cu construcție metalică premium, slidere reale pentru editare directă, butoane dedicate pentru funcții importante și un display LCD pentru navigare. Conectivitatea include MIDI 5-pin IN/OUT, USB-to-Host (audio/MIDI), USB-to-Device, intrare microfon (XLR/jack), AUX in, ieșiri TS și XLR balansate, două jack-uri de pedală și două ieșiri pentru căști. JUPITER-X suportă și Roland Cloud Connect (cu adaptorul wireless WC-1) pentru încărcare wireless de Model Expansions.
